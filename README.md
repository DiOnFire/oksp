# OKSP

Вариант 1. Сервис выдаёт читателю свободный экземпляр
книги, запрещает выдачу при текущей просрочке, принимает возврат и рассчитывает
штраф. В браузере доступны журнал с фильтром и пагинацией, карточка со
связанными данными, форма выдачи и сводка по всей базе.

## Требования

## Установка и запуск

```bash
cp .env.example .env
npm ci
docker compose up -d --wait db
npm run db:init
npm run seed:small
npm start
```

## Тесты

```bash
npm test
npm run test:integration
```

## Ручки

| Метод и путь                 | Параметры                                    | Успех                                                                               | Ошибки                       |
| ---------------------------- | -------------------------------------------- | ----------------------------------------------------------------------------------- | ---------------------------- |
| GET `/api/me`                | Нет                                          | 200: `{username,prefix,today,finePerDayRub}`                                        | 401                          |
| GET `/api/loans`             | `page=1`, `size=20`, `status`, `q`           | 200: `{items,total,page,size}`                                               | 401, 422                     |
| GET `/api/loans/:id`         | Положительный целый `id`                     | 200: `Loan`                                                                         | 401, 404, 422                |
| GET `/api/readers`           | `q` — часть имени                            | 200: `{items}`                                               | 401, 422                     |
| GET `/api/copies`            | `q` — часть названия или инвентарного номера | 200: `{items}`; только свободные                | 401, 422                     |
| POST `/api/loans`            | JSON `{readerId,copyId,dueDate}`             | 201: `{loan}`                                            | 400, 401, 404, 409, 413, 422 |
| POST `/api/loans/:id/return` | Положительный целый `id`; тело не требуется  | 200: `loan`                                              | 400, 401, 404, 409, 413, 422 |
| GET `/api/summary`           | Нет                                          | 200: `{totalLoans,onLoan,overdue,fineRub,popularBooks,asOf}` | 401                          |
